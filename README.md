## 这是什么

这不是教程，是过程记录。每个主题一个 `.cpp` 文件，写完就跑一遍，注释里留下当时真实的理解——包括理解错、后来才想明白的部分。

代码会保留原样，想到更好的写法再改；读起来像笔记，不像教材。

## 已经记下来的几件事

这些都是写代码时踩到、或反复看才记住的点：

- **short 会溢出**：`short` 存 `50000` 会回绕成负数，赋值给不同宽度类型时要先想清楚范围（`basic_test.cpp`）。
- **`while(count--)` 的顺序**：后置递减先判断真假、再减一，所以循环体里的 `count` 比外面小 1。
- **`static` 的三种含义**：修饰局部变量时值在函数调用之间保留；修饰全局变量/函数时具有内部链接，只在本文件可见。
- **指针 `+1` 不是加一个字节**：移动的是 `sizeof(类型)`；两个指针比较大小只在指向同一个数组的元素时才有意义。
